About AI.CREATIVE

A student mini-project designed to make writing support smarter, secure, and more practical.

What does this website do?

AI.CREATIVE is an AI-enhanced creative writing platform. It helps users convert rough ideas into polished writing, correct mistakes, improve sentence quality, and make content presentation-ready. The platform supports creativity instead of replacing it.

✅ Secure account creation with email OTP
✅ Username/password based login
✅ AI generation, correction, and enhancement
✅ PostgreSQL-based user and history storage

Features that make it powerful.

A clean landing page, secure authentication, practical AI tools, and a real deployment-ready flow make this project feel complete.

Creative Generation

How the platform works

1

Verify Email

Create Account
